# Professional Development Design Studio

An original browser-based design studio for turning a professional learning priority into a focused, active, and supported development pathway. Visitors choose a practice priority, layer evidence-informed learning moves, select a transfer rhythm, and download a personalized completion badge for sharing on LinkedIn.

> **Live interactive preview:** `https://highimpact360.github.io/professional-development-design-studio/`

## Why this project is different

This is a **planning studio**, not a quiz or a branching scenario. It invites users to build a short, visible design brief around a professional development priority. The experience emphasizes practical design choices that can make professional learning more relevant, active, collaborative, coached, and sustained.

## Interaction flow

1. **Frame** a specific practice-connected development priority.
2. **Design** the experience by selecting at least three learning moves.
3. **Support transfer** through a coaching, inquiry, or showcase rhythm.
4. **Share** a personalized completion badge downloaded locally as a PNG. The LinkedIn control opens a share draft; users attach the downloaded badge themselves before posting.

The completion badge recognizes engagement with this reflection activity. It is **not a credential, certification, assessment result, or evidence of competency**.

## Evidence-informed foundation

The studio turns well-established professional learning themes into an approachable design exercise. It does not evaluate individuals or institutions, forecast impact, or use organizational data. The public site presents the following research-informed prompts:

- Begin with a meaningful, practice-connected priority.
- Make space for active learning, collaboration, feedback, rehearsal, and reflection.
- Support transfer through coaching and sustained follow-up rather than relying on a single event.

## Technology

- Semantic HTML5
- CSS custom properties, grid, transitions, and responsive design
- Vanilla JavaScript state management
- Local Canvas API badge generation (`.png` download)
- No external data collection or server-side storage

## Run locally

Open `index.html` in a browser, or serve the folder from any static HTTP server.
